# Aprender+ | Módulo B2 Design

Arquivo de design em Figma criado para o módulo B2 do projeto-teste Aprender+, utilizado na preparação para a modalidade Desenvolvimento de Aplicativos Móveis.

O enunciado propõe uma experiência educacional para explorar cursos, agenda e perfil. O arquivo `.fig` é a entrega de design deste módulo.

## Abrir o projeto

Importe `08_Modulo_B2_XX.fig` no Figma usando a opção de importar arquivo. O projeto pode ser explorado no editor após a importação.

## Contexto

Trabalho de treino baseado em material de projeto-teste da WorldSkills. O enunciado e os recursos fornecidos serviram de referência para a criação.
